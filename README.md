## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoStudioPro.git`
2. `cd CryptoStudioPro`
3. Install in editable mode: `pip install -e .`

## Configuration

CryptoStudioPro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
